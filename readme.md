# 💧 Nhắc Uống Nước · Vận Động · Nghỉ Ngơi

Ứng dụng PWA nhắc uống nước, vận động, nghỉ ngơi + phát nhạc + tùy chỉnh giao diện.

## Tính năng mới

- **Chỉnh giao diện**: 6 chủ đề (Sáng / Tối / Xanh / Tím / Cam / Hồng) + chọn màu chính
- **Hình nền**: chọn ảnh từ máy, chỉnh độ mờ lớp phủ
- **Phát nhạc local**: chọn file MP3/M4A/WAV/... từ máy, phát / tạm dừng / dừng / lặp lại

## Cài đặt trên điện thoại

### Android (Chrome)
1. Mở `index.html` bằng Chrome
2. Menu ⋮ → **Thêm vào màn hình chính** / **Cài đặt ứng dụng**

### iPhone (Safari)
1. Mở bằng Safari
2. Chia sẻ → **Thêm vào Màn hình chính**

## Cách dùng

1. Cho phép **thông báo**
2. Bật các nhắc (hoặc **Bật tất cả**)
3. Nhấn ⚙️ để đổi giao diện / hình nền
4. Trong phần **Nhạc thư giãn** → **Chọn file** để phát nhạc từ máy

## File trong gói

- `index.html` – app chính
- `manifest.json` – PWA
- `sw.js` – Service Worker
- `icon-192.png` / `icon-512.png` – icon
- `README.md` – hướng dẫn
